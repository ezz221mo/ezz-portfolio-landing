## 🔧 التخصيص (Customization)

### تغيير الألوان
قم بتعديل متغيرات CSS في `style.css`:

```css
:root {
    --primary-gold: #YOUR_COLOR;
    --dark-gold: #YOUR_COLOR;
    /* ... الخ */
}
```

### إضافة مشاريع جديدة
أضف بطاقة مشروع جديدة في قسم المشاريع:

```html
<div class="project-card">
    <div class="project-icon">
        <i class="fas fa-icon-name"></i>
    </div>
    <h3 class="project-title">اسم المشروع</h3>
    <p class="project-description">الوصف</p>
    <div class="project-tech">
        <span>التقنية 1</span>
        <span>التقنية 2</span>
    </div>
</div>
```
